## The central distinction

Three statements must remain separate:

1. An adaptive description has an abstract fixed enlarged-state equivalent.
2. That equivalent can be implemented in a specified physical comparator
   with the same interface and an explicit resource budget.
3. A new principle reduces possibilities beyond the comparator's earned
   standard constraints.

PR #6 established (1) for its stated class. This package establishes some
instances of (2), some resource lower bounds, and some obstructions to
narrow subclasses. It establishes no instance of (3). Enlarging state
can incur real memory, ancilla, latency or entropy costs. Paying those
costs with ordinary apparatus often restores equivalence. An obstruction
to a gratuitously restricted comparator is not a fundamental discriminator.
