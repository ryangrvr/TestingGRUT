# SCOUT-2 ZOOM-OUT 07 (after REPAIR 04 and S2-G2/G3/G4)

## The owner's eight questions

**1. Is ANY notion of dimension independently supplied once its parent structure is given?**
**No, except G1, which *is* part of Σ.**

| notion | computed from, with no further dimension input |
|---|---|
| d_g, d_s, d_w | the graph + probe walk (+ scale, + site) |
| causal dimension | the order (+ region, + estimator) |
| N | the state space + effects (+ dynamics) |

What remains supplied is the **parent structure**, not "a dimension".

**2. Which are genuine derived observables?** d_g, d_s, d_w, d_causal and N are all **derived observables**. Each is
*nonunique as a descriptor*:
- Sierpinski gives three different numbers on one graph;
- cospectral graphs share d_s but differ in d_g;
- the comb shares d_g with the square lattice but differs in d_s;
- N = 2 across K = 1 … 4.

**3. Which depend on Σ?**
- **G1** = Σ.
- **G2:** the interaction graph is drawn on Σ's factors (S2-1b / S2-Σ).
- **G3:** needs individuated events.
- **G4:** composite capacity needs a composition rule. The rule is benign for N in the tested cases but not for K (real
  QM: 9 ≠ 8).

**4. Which depend on A?**
- **G4 strongly:** collective readout 4 → 3; a restricted qutrit 3 → 2; unsharp effects → 1.
- **G2:** the probe scale and the site / averaging choice (comb backbone 1.51 vs tooth 1.00).
- **G3:** the estimator and its domain of validity. Applying the interval-calibrated MM to a slab gives 5.45 for parent 3.
  That is an estimator failure, not a change of dimension (REPAIR 05).

**5. Can G2 determine G3? If not, what extra causal structure is needed?** **No.**
- The same ℤ² spatial graph gives different causal-order statistics: an MM-equivalent ordering-fraction dimension of ≈ 2.9
  with finite-speed cones and 1.14 with absolute time. These are effective order dimensions, not calibrated spacetime
  dimensions (REPAIR 05).
- The extra input is a **finite-speed propagation rule (a causal order)** plus an **interval-type region**.
- Even then **Lorentz structure is not derived**: lattice cones are anisotropic (1.39 – 1.94) with quadratic dispersion.
  In causal sets, Lorentz invariance is inherited from the sprinkling parent.

**6. Can G4 determine G1 / C4? If not, what is missing?** **No.**
- N = 2 is shared by the bit, rebit, gbit / polygons, qubit and spin factors, and by an access-restricted qutrit (d = 3).
- Missing:
  - the state-space shape (K and its symmetry);
  - the effect structure (no-restriction vs restricted);
  - the composition rule (local tomography distinguishes real from complex QM through K_AB, not N_AB).

  These are exactly the C4 / C5 ingredients SCOUT-1 and S2-2 / S2-5 dealt with.

**7. Has the residual C5 boundary shrunk?** **Yes, conceptually.**
- C5-G ("dimension") is **eliminated as a single primitive**.
- It is replaced by derived observables of four different parents:
  - the interaction graph + probe dynamics (D / Σ);
  - causal order + region (D_order);
  - the state / effect / access structure (A + C4);
  - Σ's local d.
- This is genuine **conceptual compression**, not primitive elimination: the parents are still supplied.

**8. Is the infinite-spectrum arrow loophole still high-information?** **Medium.** G2 / G3 show that continuum limits
are where dimension *values* become sharp (finite-size windows closed by t ≈ 10 for α = 0.5). D0 shows that finite
systems cannot select an arrow. An infinite / continuous-spectrum probe would test both together, but it attacks an
already-understood scope boundary rather than a new wall.
