# PRIMITIVE LANGUAGE MATRIX

Which primitive languages could host C5 emergence, and what each **already contains**: the inserted-structure risk.
"✗" = absent, "~" = partial / implicit, "✓" = present by declaration.

| Primitive language | A individuation | B composition | D states / effects | E probability / measure | Access / interventions | Main inserted-structure risk |
|---|---|---|---|---|---|---|
| deterministic dynamical system (X, f) | ✗ | ✗ | ✗ | ✗ (invariant measures exist; none earned) | ✗ | factorization of X is a choice |
| finite automaton / cellular automaton | ~ (cells declared) | ~ (Cartesian product declared) | ✗ | ✗ | ✗ | the cells *are* individuation |
| causal set / event structure | ✗ | ✗ | ✗ | ~ (Poisson sprinkling measure) | ✗ | the sprinkling measure |
| causal graph / DAG (causal inference) | ~ (nodes) | ~ (product of node variables) | ~ | ✓ (joint distribution) | ✓ (do-interventions) | interventions and distributions declared |
| stochastic process | ✗ | ✗ | ~ | ✓ | ✗ | probability declared |
| Hilbert space + H (no TPS) | ✗ | ✗ | ✓ | ~ (Born implicit) | ✗ | the linear structure; Born |
| operator algebra (net of algebras) | ~ (subalgebras) | ~ (commuting / split) | ✓ | ✓ (states = functionals) | ~ | the algebra net = access |
| process theory / category | ~ | ✓ (monoidal product declared) | ✓ | ~ | ✓ | composition declared |
| GPT / operational probabilistic theory | ✓ | ✓ | ✓ | ✓ | ✓ | C5 declared wholesale (excluded as a starting point) |
| sheaf / contextuality framework | ~ (measurement contexts) | ~ | ~ | ✓ (empirical models) | ✓ (contexts) | contexts = access |
| algorithmic information (Kolmogorov / Solomonoff) | ✗ | ✗ | ✗ | ~ (universal prior, machine-dependent) | ✗ | the choice of reference machine |
| thermodynamic resource theory | ✓ | ✓ | ✓ | ✓ | ✓ (free operations) | everything declared |
| relational / network (graph + weights) | ✗ | ✗ | ✗ | ✗ | ✗ | the weights; the graph |

**Selection for Wave 1:** start from the **least-loaded** languages:
1. a Hilbert space + H with no TPS (for A/B: tests individuation from dynamics alone);
2. deterministic dynamics (for E/D/H).

Use causal graphs and operator algebras only as hostile comparators.
