## PF-1 — Exact adiabatic reduction

**Finite-graph identities** (any finite G; exact; KNOWN / REDERIVED). With Z_T(J) = Σ_σ e^{βΣ_b J_b s_b}:
- ∂_{J_b} log Z_T = β⟨s_b⟩_J;
- ∂²_{J_b J_b′} log Z_T = β² Cov_J(s_b, s_b′).

So for 𝓕_T(J) := (μ/2)Σ_b J_b² − T log Z_T(J):

  ∂_b 𝓕_T = μJ_b − ⟨s_b⟩_J,  **H_bb′ = μδ_bb′ − β·Cov_J(s_b, s_b′)**.

**Statements that need the adiabatic limit ε → 0** (at fixed finite N; averaging principle, KNOWN):
- For frozen J, the Glauber chain is irreducible on a finite graph and has the unique stationary law ∝ e^{βΣJ s}.
- On the slow time t′ = εt, J converges to the diffusion **dJ = −∇_J𝓕_T dt′ + √(2T′) dB′**.
- The spin-fluctuation term ε(s_b − ⟨s_b⟩) contributes diffusion of order ε·τ_corr(N) relative to the explicit noise.
  It vanishes as ε → 0 **at fixed N**. The order of limits (ε → 0 before N → ∞) is a stated assumption.
- The reduced process is a reversible gradient diffusion with stationary law **∝ e^{−𝓕_T/T′} = Z_T^{T/T′}·e^{−(μ/2T′)ΣJ²}**
  (CPS-type, n = T/T′).
- **Its deterministic stationary points satisfy μJ_b = ⟨s_b⟩_J and depend on (T, μ) only, not on T′.**

**Exact at finite ε, equal temperatures (PROVED HERE, elementary).** If T = T′, the joint law
P(σ, J) ∝ exp[−β((μ/2)ΣJ² − ΣJ_b s_b)] is invariant, and the joint dynamics is **reversible**:
- each spin flip satisfies detailed balance with respect to P(· | J);
- each J-Langevin step is the gradient diffusion for −log P(J | σ) at temperature T.

For T ≠ T′ there is no product-form invariant law in general. **The entropy production / heat flow at finite ε is not
computed in this preflight (OPEN; required by C3R-01 before any finite-ε claim).**

## PF-2 — Symmetries and gauge quotient

**Gauge action.** For η ∈ {±1}^V: σ_i → η_iσ_i, J_ij → η_iη_jJ_ij.

| level | statement |
|---|---|
| H and the Glauber rates | ΔH for a flip at i is 2σ_i Σ_j J_ij σ_j. It is invariant, so the spin dynamics is equivariant |
| J-SDE | J′ = η_b J (with η_b = η_iη_j) satisfies dJ′ = ε(s′ − μJ′)dt + √(2εT′)·η_b dB_b. **Pathwise** symmetry holds only if the Brownian increments are also transformed (B_b → η_b B_b). Since η_b B_b is again a Brownian motion, the law of (σ, J) is invariant: **symmetry in law, not pathwise for fixed noise** |
| 𝓕_T | invariant: Z_T(ηηJ) = Z_T(J) by σ → ησ; ΣJ² is invariant |

**Global flip.** The global flip is the gauge element η ≡ −1, which acts trivially on J. The group acting effectively on J
is (Z₂)^V / {±1}.

**Gauge invariants.** For a cycle C, the holonomy is h_C(J) = Π_{b∈C} sgn J_b, defined when J_b ≠ 0 on C.
- On the L-torus (L ≥ 3), the cycle space is generated by the plaquettes together with three winding cycles,
  H₁(T³; Z₂) ≅ Z₂³.
- **Equivalence to the positive sector.** A configuration with full support is gauge-equivalent to |J| **iff h_C = +1
  for every cycle**. Equivalently: all plaquettes are unfrustrated **and** all three winding holonomies are +1.
- With zeros, the same holds on the support graph G_J = {b : J_b ≠ 0}.
- **Further invariants:** magnitudes |J_b|, J_bσ_iσ_j, J_b², and plaquette products Π_{∂p}J_b.

**Architecture is counted modulo:** local gauge (which contains the global flip), translations, and lattice automorphisms.
That is C3-F2.

## PF-3 — Homogeneous-state stability

**Linearisation at J = 0 (PROVED HERE).** At J = 0 the spins are i.i.d. uniform. For b ≠ b′, s_b and s_b′ share at most
one site, so E[s_b s_b′] = 0. Hence Cov_0(s) = I and **H(0) = (μ − β)·I**.

J = 0 is locally stable iff T > 1/μ, so **T_lin = 1/μ** (exact, any finite graph). At T_lin, **all |E| directions lose
stability simultaneously** (complete degeneracy), so the bifurcation is decided by the nonlinear terms.

**Firewall (C3R-10 text).** T_lin is the **local** loss of stability of J = 0. It is **not** the thermodynamic or
adaptive transition. In fact:

**Subcritical ferromagnetic branch (PROVED HERE, using the KNOWN 3D Ising high-T series).**
- On the uniform ray J ≡ j = KT, stationarity is μTK = e(K), where e(K) = ⟨s_b⟩ is the nearest-neighbour correlation of
  the uniform Ising model at coupling K.
- The high-T series on the cubic lattice (one plaquette per bond, N_p/|E| = 1) gives
  **e(K) = K + (11/3)K³ + O(K⁵)**. So e(K)/K > 1 for small K > 0, and e(K)/K → 0 as K → ∞.
- Hence m* := max_K e(K)/K > 1, and **non-zero uniform stationary points exist for T_lin < T ≤ T* := m*/μ**: an unstable
  small branch near J = 0 and a large ordered branch with |J| → 1/μ.
- The adaptive transition is therefore **first-order-like (subcritical)**, at some T₁ ∈ (T_lin, T*] where 𝓕 values cross.
- The exact value of m* (3D Ising) is **not computed**.
- **Tiny-graph illustration (secondary).** On the single cube, e/K = 1.004, 1.017, 1.072, 1.277 at K = 0.05 … 0.4,
  matching the cube series 1 + (5/3)K², peaking and then falling. At T = 1.1 and 1.3 (μ = 1), J = 0 **and** the ferro
  branch are both local minima; J = 0 has the lower 𝓕 at T = 1.3.

## PF-4 — Exact loop structure and Landau form

**Exact identity (KNOWN).**

  Z_T(J) = 2^{|V|} Π_b cosh(βJ_b) · Σ_{Γ even} Π_{b∈Γ} tanh(βJ_b).

**Expansion.** On the cubic L-torus with **L ≥ 5**, the even subgraphs of fewer than six bonds are the empty set and
single plaquettes. Hence:

  log Z_T = |V| log 2 + Σ_b log cosh(βJ_b) + Σ_p Π_{b∈p} tanh(βJ_b) + O(J⁶).

At this order there is no disconnected-pair correction: products of two plaquettes enter at O(J⁸), and their cluster
corrections only from O(J⁸).

**Landau form (PROVED HERE to quartic order).** Using log cosh x = x²/2 − x⁴/12 + … and tanh x = x + O(x³):

  **𝓕_T = const + (μ/2 − 1/(2T))Σ_b J_b² + (1/(12T³))Σ_b J_b⁴ − (1/T³)Σ_p Π_{b∈∂p} J_b + O(J⁶).**

**Finite-torus corrections:**
- L = 4: winding cycles of length 4 add quartic terms (1/T³)Π_{winding} J.
- L = 3: winding cycles of length 3 add **cubic** terms.
- L = 2: multi-edges.

The quoted form holds for L ≥ 5.

**Classification of terms (C3R-08):**
1. bond-local quadratic: (μ − β)/2·J²;
2. bond-local nonlinear: +β³J⁴/12, which is stabilising;
3. **first inter-bond, gauge-invariant term = the plaquette term** −β³Π_{∂p}J. It favours unfrustrated plaquettes
   (ΠJ > 0) and penalises frustrated ones;
4. the first closed plaquette contribution is the same term. It has **bounded support (four bonds), so it is NOT C3
   collectivity.**

**The truncation is not stabilising.** On the uniform ray the quartic coefficient per bond is β³(1/12 − 1) < 0. So no
global stability is inferred from the truncated form, consistent with the subcritical branch of PF-3.

**Small-amplitude structure near T_lin (PROVED HERE, Landau level).** Write 𝓕 = aΣJ² + cΣJ⁴ − dΣ_pΠJ, with
a = (μ − β)/2, c = β³/12, d = β³. For a quartic Landau function, nonzero stationary points correspond to critical
points of φ(u) = cΣu⁴ − dΣ_pΠu on the unit sphere with φ > 0 (a < 0). Local minima of 𝓕 correspond to local minima of φ
there.

- **Uniform (ferro) direction.** φ < 0, so there is no small branch for T < T_lin, only the subcritical branch above it
  (as in PF-3).
- **Fully frustrated (FF) direction.** J_b = jη_b with every plaquette product Π_{∂p}η = −1. Such patterns exist on the
  cubic lattice (the standard fully frustrated simple cubic model).
  - Each bond lies in four plaquettes, so stationarity gives j² = −a/(2(c + d)) > 0 for T < T_lin. **A supercritical FF
    branch exists.**
  - Its Hessian, after the gauge rotation by η, is (8c − 4d)j²·I + dj²·A. Here A is the "two bonds share a plaquette"
    adjacency matrix, which has zero diagonal, so trace 0 and λ_min(A) < 0.
  - Since 8c − 4d = β³(2/3 − 4) < 0, the smallest Hessian eigenvalue is β³j²(−10/3 + λ_min(A)) < 0. **The FF branch is a
    saddle.**
- **General small-amplitude frustrated minima.** The full classification of local minima of φ on the sphere with φ > 0
  is **OPEN**.

## PF-5 — Ferromagnetic-envelope theorem (C3R-10) and a local-minimum frustration bound

**THEOREM PF5-E (envelope; PROVED HERE).** For every finite graph, every J ∈ ℝ^E and every T > 0:

  **Z_T(J) ≤ Z_T(|J|), hence 𝓕_T(J) ≥ 𝓕_T(|J|).**

**Equality holds iff J is gauge-equivalent to |J| on its support,** i.e. every cycle in G_J has holonomy +1 (on the
torus, winding cycles included).

*Proof.*
- **Inequality.** cosh(βJ_b) = cosh(β|J_b|). Every even subgraph has |Π_Γ tanh(βJ_b)| = Π_Γ tanh(β|J_b|), so the sum is
  bounded termwise. ΣJ² is unchanged.
- **Strictness.** An even subgraph is an edge-disjoint union of cycles, and its sign is the product of their holonomies.
  If some cycle C ⊂ G_J has h_C = −1, the term Γ = C is strictly smaller than its absolute value (tanh(β|J_b|) > 0 on the
  support). Conversely, if all holonomies are +1, all terms coincide. ∎

**COROLLARY.** **Every global minimiser of 𝓕_T is unfrustrated:** gauge-equivalent to a nonnegative configuration on its
support, with trivial winding holonomies. A frustrated J can never be a global minimiser, let alone a unique one.

**This says nothing about local minima.** The next theorem addresses them.

**THEOREM PF5-L (local-minimum frustration bound; PROVED HERE).** Let J be a stationary point of 𝓕_T whose Hessian has
nonnegative diagonal. Every local minimum qualifies. Then:

1. **Var_J(s_b) ≤ μT for every bond b.**
2. **Every cycle C ⊂ G_J with holonomy −1 has length |C| ≥ 2/(μT) = 2·T_lin/T.**

*Proof.*
- **Part 1.** H_bb = μ − β·Var(s_b) ≥ 0.
- **Part 2, sign matching.** Stationarity μJ_b = ⟨s_b⟩ makes sgn⟨s_b⟩ = sgn J_b. Call bond b unsatisfied in σ if
  s_b·sgn J_b = −1. Then P(b unsatisfied) = (1 − |⟨s_b⟩|)/2.
- **Part 2, variance bound.** Var(s_b) = (1 − |⟨s_b⟩|)(1 + |⟨s_b⟩|) ≥ 2·P(b unsatisfied).
- **Part 2, frustrated cycle.** If h_C = −1, then Π_{b∈C} s_b·sgn J_b = −1 for every σ, so **every** configuration
  leaves at least one bond of C unsatisfied: Σ_{b∈C} P(b unsatisfied) ≥ 1.
- **Part 2, conclusion.** 2 ≤ Σ_{b∈C} Var(s_b) ≤ |C|·μT. ∎

**COROLLARIES** (finite graph, exact):
- **(i) T < T_lin.** Every bond of a local minimum has Var(s_b) < 1, so ⟨s_b⟩ ≠ 0. Hence **G_J = E (full support)**,
  with |J_b| ≥ √(1 − μT)/μ.
- **(ii) T < T_lin/2.** Combined with (i), **every plaquette is unfrustrated**, so every contractible cycle is
  unfrustrated. Modulo gauge, every local minimum on the L-torus is a **nonnegative configuration in one of at most 8
  winding sectors** (Z₂³). A twisted sector needs a frustrated winding cycle, allowed only when L ≥ 2T_lin/T.
- **(iii) Untwisted sector (KNOWN: Griffiths).** For J ≥ 0, Griffiths I and II make Φ(J) := ⟨s⟩_J/μ a monotone
  self-map of [0, 1/μ]^E.
  - By Tarski, least and greatest fixed points exist: the least is J = 0.
  - The greatest fixed point is unique, so it is invariant under every lattice automorphism: it is **uniform**.
  - Non-uniform intermediate fixed points are **not excluded** here.
  - For T < T_lin/2: |J_b| ≥ √(1 − μT)/μ > (1/√2)/μ, so K_b = β|J_b| > (1/√2)·T_lin/T > √2. That is deep in the
    ordered regime (3D Ising K_c ≈ 0.22). A convergent low-T
    cluster expansion (a KNOWN technique) would give strict convexity of 𝓕_T on that region, and hence uniqueness, for T
    below some T₀. **T₀ is not computed: OPEN.**

**Secondary check** (exact enumeration, μ = 1; `c3/c3_preflight_check.log`):
- **Envelope inequality:** holds in 4000 random (J, T) samples, and is strict in every frustrated sample (993 / 993
  plaquette, 1938 / 1938 cube).
- **Stable minima:** every one satisfies Var(s_b) ≤ μT.
- **Frustration:** no frustrated stable minimum was found at any T ∈ {0.3, …, 1.3} on the plaquette or the cube.
  Theorem PF5-L forbids them only for T < 0.5, so above 0.5 the absence is an observation, not a theorem.
- An apparent "frustrated minimum" in the first run was the J = 0 minimum with round-off signs. It was removed by a
  declared computational zero (1e-6), recorded in the ledger.
