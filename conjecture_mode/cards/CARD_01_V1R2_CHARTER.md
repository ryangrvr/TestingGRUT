## 2. Criterion: LOWER-MINIMUM REPRODUCIBILITY

*This supersedes the v1R "A and B must agree" rule, for v1R2 only.*

A target is **numerically reproduced** iff all three hold:
1. at least two genuinely distinct starts reach minima whose χ² values agree within **0.2**;
2. those agreeing minima are the lowest basin found;
3. no executed start is more than 0.2 lower.

**Operationally** (`code/card01_v1r2_lib.py`):
- Let L = the minimum over **all** executed starts for the target: v1R arms A and B, plus every v1R2 start, converged or not.
- The target is reproduced iff **≥ 2 cycle-converged starts have χ² ≤ L + 0.2**.

A start that converges to a **higher** local minimum does **not** by itself cause failure. All higher minima stay in the record.

## 4. Stage B: only if Stage A passes

**Continuation sweeps.** Starting from the branch-minimum grid point (the lowest value in the pool), two sweeps run in parallel: one toward ε = 0 and one toward ε = −1.
- At each grid point, the new start is the **converged neighbouring solution with ε changed**.
- The best existing solution at that ε (v1R / v1R2) stays in the pool, and the lower refined minimum is kept.
- **No smoothing.**

**Load-bearing verification**, using the §2 criterion, covers:
- the final branch minimum;
- ΛCDM;
- CPL;
- the grid points bracketing both Δχ² = 3.84 crossings;
- the free-ε minimum.

The free fit also fails if any fixed-ε grid point lies more than 0.2 below it.

**Extra routes for a failing target, one per load-bearing iteration, at most 2 iterations:**
- **grid point:** continuation from the reverse-direction neighbour (the one the sweep did not use); then the free-ε low solution projected to that ε;
- **free fit:** the lowest grid solution with ε released.

**Outcome.**
- If every load-bearing target passes: **PRIMARY NUMERICALLY RESOLVED**, and the unchanged `decide()` is applied with the §0 label.
- Otherwise: **PRIMARY NOT NUMERICALLY RESOLVED**, with no S5 state.
