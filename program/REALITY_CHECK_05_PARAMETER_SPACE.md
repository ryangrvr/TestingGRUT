## 1. The surviving window

Current experimental/theoretical state of the DP model's single free parameter `R_0`
(the Gaussian smearing width of the mass density, DP's ONLY free parameter):

| Bound | Value | Type | Source |
|---|---|---|---|
| Lower | `R_0 ≳ 4×10⁻¹⁰ m` (4 Å) | **EMPIRICAL EXCLUSION** | Donadi et al. 2021 underground radiation test ([arXiv:2111.13490](https://arxiv.org/abs/2111.13490)) |
| Upper | `R_0 ≲ 10⁶ Å` (0.1 mm) | **CONSISTENCY CONSTRAINT** (not data) | Effectiveness requirement, NJP 26, 113004 (2024) |

**Surviving territory: ~6 orders of magnitude, IF the theoretical upper bound is accepted.**

The upper bound comes from requiring the collapse to be *effective* — large enough that
macroscopic superpositions are suppressed before we can see them. The [NJP 2024 paper](https://iopscience.iop.org/article/10.1088/1367-2630/ad8c77) itself flags it as
"reasonable (although to some degree arbitrary)." It is not data. If the demand is
relaxed (e.g. only some macroscopic systems collapse effectively — which that paper
explicitly finds), the window widens or softens.

Earlier indirect bounds (gravitational-wave detector data, neutron-star heating,
cryostat heat leakage — all from the same Brownian-diffusion indirect effect) are
**superseded** by the Donadi 2021 direct radiation bound, which is ~3 orders stronger.
