## SCOUT-1 question

> **Can any physically defensible principle FIX a quotient value — `P ⇒ Q = Q*`, or
> `P ⇒ Q ∈ S` with S strictly and meaningfully smaller — rather than merely constrain, classify or reparameterize it?**

"Given Q, X follows" is **not** the target.

**Standing hostile test for every selector `P ⇒ Q*`:**
1. Can Q vary while P holds?
2. Did P silently contain Q?
3. Is Q representation-dependent?
4. Is Q physical or gauge?
5. Is the selector already standard?
6. Does it survive parent variation?
7. Does it survive composition?
8. Does it survive coarse-graining?
9. Is Q unique, or only stationary?
10. Is a boundary condition doing the selecting?

A supplied value renamed as a principle is rejected.
