## Screen question

**Can any named principle plausibly choose between two already-admissible surviving worlds without being supplied
equivalent information telling it which one to choose?**

The screen **does not assume** that one exists.

## Absolute rule (owner)

A candidate is **not** a selector merely because it does any of the following:
- makes one solution aesthetically preferred;
- forbids more solutions;
- produces a unique answer after a boundary condition is supplied;
- extremizes an arbitrarily selected objective;
- inserts a dimensional scale;
- assumes a state, vacuum, measure, prior, reference frame, partition, coarse-graining, sign, asymptotic structure or
  modular pattern equivalent to the target;
- reconstructs a large structure from a compact seed carrying the same selecting information;
- calls an interpretive identification a derivation.

## Environment limitation (recorded up front)

Direct fetches of arXiv / publisher full text are blocked by this environment's egress proxy (observed throughout prior
campaigns). The best obtainable grade from this environment is therefore usually **PRIMARY ABSTRACT VERIFIED** (abstract
text retrieved via search) or **SOURCE LOCATED**. No verdict here rests on a grade higher than the one recorded.

**Kill verdicts** rest on **structural input accounting**: what the principle must be given in order to output its choice.
That is checked against the abstract-level statement of the principle and against frozen results. **GO verdicts would
require more**, and none may rest on a search summary alone.
