## I1 — RG fixed points / universality

| C | content |
|---|---|
| C0 | the effective variables / scale / dimension are those of the RG fixed point governing a basin |
| C1 | scale / dimension / coarse-graining |
| C2 | W-A2; W-scale (unit u vs u′) |
| C3 | the UV action; the RG map (block rule / cutoff / scheme); the dimension; the symmetries; the scale direction |
| C5 | universality is **many-to-one**: it classifies microscopic realizations into basins and does not choose one. Only universal data are scheme-independent (Latorre–Morris).
