# SELECTOR CHALLENGE — entry conditions for any future selector campaign

**This is NOT a selector campaign.** It defines what a candidate selector must satisfy **before** a campaign may open.
No candidate is proposed here. The target is the frozen joint class in `CONSTRAINT_COUPLING_MAP.md`.

## 1. Entry conditions (all required)

| ID | condition | test |
|---|---|---|
| **S0** | **Named target** | identifies at least one currently supplied target: orientation; A_resolution / coarse-graining; A_time; subsystem / partition choice; modular-position pattern; H_epoch; H_cross within its surviving admissible class; dimension; physical scale (or another row of `MASTER_RESIDUAL_LEDGER.md` graded SUPPLIED / NOT SELECTED / CONSTRAINED-NONUNIQUE) |
| **S1** | **Actual information elimination** | the target becomes unnecessary, or is uniquely fixed from inputs carrying strictly less equivalent selecting information. **Forbidden successes:** renaming; dimensional insertion; state-pricing; boundary-condition pricing; modular-pattern pricing; charge-sector pricing; interpretive identification |
| **S2** | **Selection, not another no-go** | chooses among ≥ 2 members that **both survive every frozen admissibility constraint**. Forbidding another subclass is CONSTRAINED-NONUNIQUE, not selection |
| **S3** | **Coupled-class action** | operates on the surviving **joint** constrained residual (the couplings E-S1 … E-G12), not on an independent-variable picture |
| **S4** | **Frozen controls** | reproduces, or explicitly pays for violating: finite / type-I controls; flat AQFT; G → 0; the QFT sharp / split distinction; gravitational observable-class dependence; the asymptotic-access results |
| **S5** | **Anti-smuggling** | for every selector input X: if X changes while all frozen physics is retained, does the selected result change? If yes, X is load-bearing and must be priced as supplied |
| **S6** | **Symmetry / convention firewall** | the choice survives orientation reversal (where admissible), algebra / commutant exchange (where admissible), coordinate / unit changes, gauge-equivalent descriptions and equivalent representation changes. Otherwise it is convention-priced |
| **S7** | **Seven-criterion payoff bar** | any selected result claimed as a physical prediction must be forced · residual-input invariant · convention invariant · nontrivial · distinctive · observable · falsifiable |

## 3. Pre-registered failure modes (any one ⇒ the candidate is not a selector)

| failure | how it shows up | grade it would receive |
|---|---|---|
| the target reappears as a declared input elsewhere | the S5 test changes the result | RELOCATION |
| the selected value carries an inserted dimensionful constant | ℓ_P-type insertion | RELOCATION / SCALE INSERTION |
| the selector only removes a subclass | the S2 table's two members both survive | CONSTRAINED-NONUNIQUE |
| the choice flips under an admissible symmetry | S6 | CONVENTION-PRICED |
| the selector needs a state / vacuum / boundary choice equivalent to the target | S1 | STATE- / BOUNDARY-PRICED |
| interpretive identification ("X *is* time / orientation / the subsystem") | S1 | INTERPRETIVE HYPOTHESIS, not derivation |

## 4. GO / NO-GO rule

A selector campaign may open **only if** a **named** candidate can plausibly pass **S1 and S2 before any calculation
begins**. That means stating:
- which §2 row it acts on;
- which member it picks;
- what input it uses;
- why that input carries strictly less selecting information than the target.

If no candidate can even in principle eliminate supplied information **and** choose between surviving admissible members:
**DO NOT OPEN SELECTOR CAMPAIGN.**

**Screen question** (owner): *Can we name a principle that could choose between two already-admissible surviving worlds
without being told which one to choose?*
