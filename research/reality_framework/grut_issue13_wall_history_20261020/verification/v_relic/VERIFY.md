# v_relic: adversarial verification of modules/relic_yield

21 October 2026. Verifier key `v_relic`. I wrote all code here from scratch (numpy/scipy, 2 threads). I did not
import or copy module code. I read the module's NOTES.md for the claims, and its `results/boltzmann.json` only
after I had my own numbers, to locate one 2 % difference. No git except read-only `git show 2ee7f82` (Codex

## 1. Stability of h, X and D (item 1): CONFIRMED

**Method.** I expanded U at φ = v + h by hand. Each vertex and mass was checked against finite-difference
derivatives of U (`fd_vertices`; exact to 1e-9). I then enumerated the final states allowed by U(1)_X and Z2_D.

**Spectrum and kinematics [C].**

- Masses: m_X = 100, m_h = 141.4214, m_D = 100.4988 GeV.
- h → XX̄ needs 200 GeV and h → DD needs 200.998 GeV, so both are closed. Any other hidden final state is heavier,
  or is forbidden by U(1)_X or Z2_D.
- X is the lightest charged state and D the lightest Z2_D-odd state, so both are exactly stable.
- XX̄ → DD is closed at rest by 0.998 GeV.

**Loop-induced decays (h → γγ, h → SM fermions) [D].**

- No field carries both hidden and SM quantum numbers. Every non-gravitational h → SM amplitude therefore needs at
  least one portal vertex (φ²|H|², |X|²|H|², D²|H|²).
- Each portal beta function contains at least one portal coupling. The surface "all portals = 0" is therefore
  RG-invariant to all orders without gravity.
- So h → γγ and every other non-gravitational h decay vanishes to all orders in the unchanged action.
- The running |X|²D² coupling α opens no channel: m_h < 2m_X.

- ρ_c/h² = 1.05367e-5 GeV cm⁻³, so Ω h² = 2.7440e8 m Y (module 2.7437e8).
- SM g*s = 106.75 at the definition epoch, T_SM = 4m_X/ξ ≈ 5e5 GeV. Dirac ν_R with y_ν ~ 1e-12 never thermalize. If

## 3. Exact tree-level threshold zero of hh → XX̄ (item 3): CONFIRMED, with a wording correction

**Derivation [D].** The vertex factors are −iV:

| Vertex | V |
|---|---|
| hhh | 6λv |
| hXX* | 2g²v |
| hhXX* | 2g² |

At the hh threshold, s = 4m_h², t = u = m_X² − m_h², so t − m_X² = −m_h². The diagrams give:

- Contact: −2g².
- s-channel h: −(6λv)(2g²v)/(3m_h²) = −4λg²v²/m_h² = −2g², using m_h² = 2λv².
- t + u: −2(2g²v)²/(−m_h²) = +4g⁴/λ.

The sum is M_thr = −4g²(1 − g²/λ) exactly. At the benchmark g² = λ = 0.01 (⇔ m_h = √2 m_X) the three diagrams are
−0.02, −0.02 and +0.04, which sum to 0 (7e-18 numerically) [C]. A scan over a = g²/λ ∈ {0.25, 0.5, 0.9, 1, 1.1, 2}
matches the formula to 1e-15.

**Correction: the zero is not "p-wave-like".** The amplitude is even in cos θ (t ↔ u, identical initial h), so
there is no l = 1 wave. It vanishes as p² in both the l = 0 and the l = 2 waves. Hence σv ∝ v⁴: the log slope is
4.000 at v = 1.4e-3 [C]. A p-wave would give v².

**Thermal averages agree** (x = m_X/T, ⟨σv⟩ in GeV⁻²):

|---|---|---|---|---|
| hh → XX̄ | 1.47e-11 | 8.89e-12 | 1.395e-12 | 1.5e-11 / 8.9e-12 / 1.4e-12 ✓ |
| DD → XX̄ | 3.10e-16 | 3.87e-15 | 6.33e-15 | ✓ |

For hh → XX̄ at x = 20 this is 1.63e-29 cm³/s.

## 4. Minimum T_SM for a relic-compatible thermal restoration (item 4): CONFIRMED (2.05–2.10e6 GeV)

**T_c [C].** Π/T² = λ/4 + g²/6 + h_D²/12 = 0.004175, so T_c/v = 1.547646. The resummed 1.5571–1.5641 is [Q].

**Route A, T_c/ξ_max [C].**

| ξ_max | T_SM,min (leading to resummed T_c) |
|---|---|
| Module, 7.581e-4 | 2.041–2.063e6 GeV |
| Mine, 7.550e-4 | 2.050–2.072e6 GeV |
| No D (module / mine) | 1.85–1.87e6 / 1.86–1.88e6 GeV |

**ξ at T_c versus ξ at 4m_X [C].** I matched comoving number between a μ = 0 bath at T_c and the 4m_X reference.
This gives ξ_c/ξ_ref = 0.987, so route A rises by 1.3 % to about 2.07e6. The module's "constant to ~1 %" is ✓.

**Route B, number bound n ≥ n_th(T_c) [C].**

- n_th(T_c) = 4ζ(3)T_c³/π² = 1.806 v³ (1.804 v³ with m_D0 kept).
- With the module's Y_max = 4.30e-12: 2.078–2.100e6 GeV ✓.
- With the strict Y_max = 4.373e-12: 2.066–2.088e6 GeV.

**Π_φ ∝ n^{2/3} Li₂(z)/Li₃(z)^{2/3} [C].** The function is monotonic on 9 points between 1e-3 and 1 (0.100 → 1.455),
so μ = 0 restores with the fewest thermal quanta ✓. The bath-independence claim holds only for kinetically
equilibrated BE baths with μ ≤ 0. The module itself exempts coherent condensates (placeholder bound 5.4e5 GeV).

**Scaling.** (v/TeV)^{4/3} is exact for the frozen and full-conversion limits. The conversion efficiency
(Γ/H ∝ ξ² M_P/v) moves ξ_max inside the 3.3 % frozen/full-conversion band, so the scaling holds to ≲ 3 %.

## 5. Floor inequality m_X|r| + 79.28 GeV ω_sym < 63.93 GeV (item 5): CONFIRMED

**Sources [Q: Codex 2ee7f82 REPORT.md §2–4, git show].**

- The floor is ω_h,min = (m*|r|/m̄_b) ω_b, with m* = 56.234 GeV (μ = m*/m_X = 0.56234).
- The maser condition is stated as m_X|r| ≲ 63.9344 GeV (primary) or 74.6429 GeV (stress), "for fixed dimensionless
  couplings", i.e. at fixed μ.
- The primary corner uses ω_b = 0.02233 − 3·0.00036 = 0.02125 and a 1 % higher m_b = 0.94738 GeV.

**Algebra [D].**

- The condition is equivalent to (μ m_X|r|/m_b) ω_b ≤ Δω, with Δω = 0.80643 (H_floor ≤ 90.98 km/s/Mpc).
- Adding a pressureless ω_sym, which can only lower D_A, gives m_X|r| + (m_X/m*)(m_b/ω_b) ω_sym < 63.93 GeV.
- **Coefficient = 1.77828 × 44.5826 = 79.280 GeV** ✓.
- Equivalent m*-form: m*|r| + 44.58 GeV ω_sym < 35.95 GeV.
- The floor itself is on m*. The Codex number is expressed through m_X at fixed μ. The module's m_X-form is
  consistent, and the sense of the inequality is correct.
- If one wrongly used the coefficient m_b/ω_b alone, |r| < 0.586 instead of 0.544.

**Downstream numbers [C].**

- |r| < 0.5442 (primary), 0.6513 (stress) for ω_sym = 0.12 ✓.
- r = 1 floor: 113.25 → 118.43 km/s/Mpc ✓.
- ω_asym ≥ 1.3383 r with central ω_b and m_b = 0.9383 ✓, so |r| ≤ 0.0897 ✓.

**Caveat.** These two inputs use different m_b (0.94738 corner versus 0.9383 central). That is consistent with each
one's purpose but should be stated.

**Additivity caveat.** ω_h ≥ floor + ω_sym assumes the symmetric quanta stay free and nonrelativistic. The hidden
number is not a conserved charge. In dense regions, 3→2 could turn rest mass into kinetic energy that later
redshifts away. So the "rigorous weaker form" ω_h ≥ max[floor, ω_sym] is also conditional on ω_sym surviving. The
module states the assumption, but calls the max form "rigorous".

- §0 says "Each uses a potential without Z2 or an explicit bias". This is false for KLR, which keeps the Z2-symmetric

  Macpherson–Campbell (and KLR footnote 1) state that the exact limit gives the wall problem.
- "No work analyses …" is scoped to the eight papers checked. It is not a literature-wide search.
