# M1 synthesis: test protocol

Parent commit 6c504de651cb7085025f4620bdd3a37c8c5c805f. User supplied a
three-part synthesis proposal. Test it without turning conditional assumptions
into facts or altering the prior frozen candidate.

1. Check units and exact benchmark values; derive a conservative positive-energy
   stress-work bound and an explicitly assumption-dependent flux/causality
   estimate. Calculate the exact temperature-dependent cosmological clock rather
   than use the proposal's stated H/m. Do not interpret a uniform-gas crossing
   estimate as a general coherent-field or interaction theorem.
2. Check operator dimensions, charges, signs and phase Hessian with canonical
   fields. Evaluate at the actual inflationary M1 initial state; quantify EFT
   hierarchy, force, mass, and backreaction. Attempt a controlled phase-holder
   construction and explore switching/trajectory response where possible.
   Full coupled perturbations and preparation selection are separate obligations.
3. Read the actual 64/96-bin final kinetic states. Compute particle-weighted
   velocity and collisionless free-streaming distributions from 2 MeV through
   equality using a standard background and entropy transfer. Report total DM
   mass fraction separately from charge fraction and retain floor/bin errors.
   Attempt a real linear Boltzmann matter-power comparison with the published
   CLASS code if it can be installed locally; declare custom phase-space,
   initial-condition, collisionless and perturbation assumptions, plus k-range
   and numerical controls. Otherwise report an explicit inability, not invented
   values. Never infer a primordial phase-space distribution from one-point
   energy bins without stated assumptions.
4. Audit calibration scaling under fixed dimensionless history and distinguish
   it from an independently predicted abundance. Record methods, outputs,
   conservation, input hashes and unresolved obligations.
