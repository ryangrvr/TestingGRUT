# External source scope

* [CLASS public code, v3.4.1 source commit](https://github.com/lesgourg/class_public/tree/814ce59c380a5cccd0bed1747a384ff7bfc1f9cf): cosmological linear Boltzmann solver used for the exploratory comparisons. The M1 phase-space and initial-condition choices here are ours, not claims by the CLASS authors.
* [Planck 2018 results X: Constraints on inflation](https://doi.org/10.1051/0004-6361/201833887), section 9.4.1 and equation 88: the `β_iso < 0.038` 95% benchmark applies to the stated uncorrelated, scale-invariant cold-dark-matter isocurvature model. It is not automatically the bound for the heavy, mixed, time-dependent M1 perturbation.
* [Planck 2018 results VI: Cosmological parameters](https://doi.org/10.1051/0004-6361/201833910): background context for the Planck-like parameters, which we explicitly specify rather than fitting here.

The original repository action, candidate and saved data are pinned in [INPUT_PINS.json](INPUT_PINS.json). All new numerical calculations and checks in this packet are same-author work.
