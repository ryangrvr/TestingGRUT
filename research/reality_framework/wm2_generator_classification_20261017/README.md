# WM2-IG1

Read REPORT.md first, then OBSTRUCTION.md and SUFFICIENT_RULE.md. The
construction price and current decision are in ASSUMPTIONS.md. HANDOFF.md
lists the load-bearing proof challenges. This is a completed bounded
classification packet, not a new solver or a demonstrated theory of reality.

From this directory:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python verify.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python verify.py --run-checks
```

The first verifies the packet and pinned sources. The second also replays
the finite diagnostic suite without replacing CHECKS.json. Ordinary double
precision is not outward-rounded certification. EXECUTION_NOTES.md preserves
the initial setup correction and all important scope boundaries.
