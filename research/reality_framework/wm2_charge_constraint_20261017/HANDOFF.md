stored dispositions. `--run-checks` reruns the bounded small-operator and
response controls without rewriting archived results. There is no option
to run the closed formation/recovery workers. Runtime in the recorded
environment is a few seconds. All floating calculations are ordinary
double precision, not interval arithmetic or formal proof verification.
