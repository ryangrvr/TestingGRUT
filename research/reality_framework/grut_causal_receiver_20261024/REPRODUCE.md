# Reproduce the causal receiver

Requires the parent 9636950 tree, a C++17 compiler, Python, NumPy, SciPy and
Matplotlib. No new package installation was used. From the repository root:

```bash
OPENBLAS_NUM_THREADS=1 python3 research/reality_framework/grut_causal_receiver_20261024/code/discrete_layer.py
OPENBLAS_NUM_THREADS=1 python3 research/reality_framework/grut_causal_receiver_20261024/code/operator_controls.py
```

Those low-cost tests cover actual spatial-grid matching, the exact lattice
leads, executable work/gradient identities and representative complete linear
eigenspectra. The formation and packet runs take several minutes per case;
independent cases may run concurrently if CPU resources permit:

```bash
OPENBLAS_NUM_THREADS=1 python3 research/reality_framework/grut_causal_receiver_20261024/code/run.py smoke free_X free_X_time free_s free_soft
OPENBLAS_NUM_THREADS=1 python3 research/reality_framework/grut_causal_receiver_20261024/code/run.py P025 P025_time P0125 P00625 P025_remote P025_remote_time
OPENBLAS_NUM_THREADS=1 python3 research/reality_framework/grut_causal_receiver_20261024/code/run_interface.py
```

Run the interface after P025_time because its field/trace/memory hashes are
compared directly. Its generated radial_flux.cpp is included and can also
be reconstructed by code/instrument.py. Neither field dynamics nor the
initial physical tails are changed by the extraction instrumentation.

```bash
OPENBLAS_NUM_THREADS=1 python3 research/reality_framework/grut_causal_receiver_20261024/code/source_audit.py
OPENBLAS_NUM_THREADS=1 python3 research/reality_framework/grut_causal_receiver_20261024/code/bound_modes.py
OPENBLAS_NUM_THREADS=1 python3 research/reality_framework/grut_causal_receiver_20261024/code/verify.py --with-raw
python3 research/reality_framework/grut_causal_receiver_20261024/code/report.py
python3 research/reality_framework/grut_causal_receiver_20261024/code/manifest.py --check
```

All released production summaries, downsampled conserving histories,
diagnostics, raw numeric hashes and code are in the compact packet. Raw
lossless arrays are regenerated by the commands above. Without those raw
arrays, omit --with-raw for the compact recorded-result verification.
Elapsed times need not reproduce exactly; numerical controls and hashes
state what was actually checked. The author did not execute a second full
replay of every new production case or an independent Claude review.

Two coarse formation time steps fail the stricter refined energy-budget
target and are explicitly retained as controls. The longer soft-packet
case also reports its coarser bulk RK4 drift separately. Passing the vacuum
receiver test does not certify an uncomputed nonlinear particle source.
