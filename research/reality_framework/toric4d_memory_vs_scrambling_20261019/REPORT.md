# Memory versus local thermalisation in a passive self-correcting code: the bridge claim fails

**19 October 2026. Branch `claude/toric4d-memory-vs-scrambling-20261019`. Author: Claude (claude.ai), owner-directed. Pre-registration: `README.md` at commit `52b8f11`, before any production run.** Additive packet; no frozen record modified. Independent review outstanding.

## 1. Question

The last surviving sharp reading of GRUT's founding intuition joined two claims through an unstated bridge:

- **M:** the late-universe state is a passive self-correcting quantum memory whose rigidity is geometry.
- **S:** the fundamental dynamics does not scramble (λ_L < 2πT).
- **B (bridge):** a passive self-correcting memory is necessarily non-scrambling / non-thermalising in its local degrees of freedom, so M implies S.

The 19 Oct literature brief found S contradicted at the de Sitter horizon (Aalsma–Shiu 2020; Kolchmeyer–Liu 2024; Narovlansky 2025) and found no test of B. This packet tests B in the one translation-invariant model proven to be a passive self-correcting memory, the 4D toric code (Dennis–Kitaev–Landahl–Preskill 2002; Alicki–Horodecki–Horodecki–Horodecki 2010), by measuring the logical memory time and the local thermalisation time **in the same thermal trajectories**.

## 2. Model and method (as pre-registered)

4D toric code, Z-error sector: Z₂ variables on the faces of an L⁴ torus (6L⁴ faces), one constraint per edge (6 faces per edge), energy E = 2·(number of violated edges) = 2·|∂e| for an error 2-chain e. Logical readout on the X̄ membrane of plane (01): the L² faces at x₀ = x₁ = 0. Dynamics: single-face Metropolis at inverse temperature β (local, detailed balance). Decoder: zero-temperature local cooling (ΔE < 0 accepted, ΔE = 0 with probability ½) for L² sweeps, which erodes contractible membranes by boundary tension and leaves spanning sheets. Control: 2D toric code (edges of an L² torus, point-like anyons, no ordered phase) with minimum-weight perfect matching readout (pymatching). Illustration: exact 18-qubit 2D toric code with field h = 0.3, infinite-temperature OTOC by stochastic trace.

The 2-form face model is dual to the 4D Ising model; the pre-registration's first draft gave the 1-form gauge-theory β_c ≈ 0.44, which a smoke-test energy scan showed to be wrong before any memory run: the transition is between β = 0.85 and 0.95 at L = 3, 4, consistent with the duality value atanh(e^{−2·0.1497}) ≈ 0.954. The β grid was set to {0.6, 0.9, 1.0, 1.1} on that basis; the readings were not changed (README §2, §3).

Observables: O1 logical half-life t½ (first time the decoded logical autocorrelation falls to ½); O2 local thermalisation time τ_loc (1/e crossing of the equilibrium autocorrelation of a single face spin and of a single edge constraint); O3 damage spreading between twin copies driven by one random stream (secondary, update-rule dependent); O4 energy per face; O5 the 2D control; Q1 the quantum illustration. Sizes: 4D L ∈ {3,4,5} with 48/24/16 trajectories; 2D L ∈ {4,6,8,12} with 64; t_max = 10⁵ sweeps. Seeds fixed in the scripts. After the first production attempt the τ estimator was changed from an exponential least-squares fit (dominated by late-time noise once P_log ≈ 0) to the half-life; this is an estimator change, not a reading change, and was made before the reported runs.

One pre-registered observable turned out to be ill-posed. The face spin of O2 is not an observable of the code: flipping the six faces of any cube is a stabiliser (zero energy), so a single face spin is defined only modulo stabilisers and drifts at zero cost. This was recognised only after the production runs, when its autocorrelation refused to decay at β ≥ 0.9, and it was verified by the gauge check in §3. The pre-registered reading is therefore applied twice in §4: by the letter (face spin and stabiliser), and with the face spin removed, the second explicitly labelled a post-hoc correction.

## 5. What this establishes and what it does not

**Established (in this model).** Logical information and local information have independent fates. At β ≥ 1.0 the stored bit survives for a time that grows with system size (t½ = 977 → 16,400 → 79,800 sweeps at β = 1.0 for L = 3, 4, 5; beyond 10⁵ at β = 1.1 for L ≥ 4), while the local gauge-invariant observable (an edge stabiliser) decorrelates within about one sweep, independent of size, and a locally injected perturbation is erased within one sweep. A passive self-correcting memory does not keep local records and does not slow local thermalisation; it keeps exactly one global, topological bit. B is false here. Since M → S needed B, the sharp reading of the intuition reduces to two independent claims: M (geometry is code rigidity), which is unformulated and collides with the CLPW empty-de-Sitter result and the 3D no-go theorems; and S (non-scrambling), which stands alone and is contradicted at the horizon.

**Not established.** This is a classical stochastic (Davies-type) model. It measures local thermalisation and classical information spreading, not a quantum OTOC or a Lyapunov exponent in the 4D code (96 qubits at L = 2 is out of reach here). The open question "can a passive self-correcting phase carry a Lorentz-invariant spin-2 sector" is untouched. Nothing here concerns de Sitter. The cooling decoder is local and not minimum-weight; its possible failure mode (a large contractible membrane drifting into a wrapping one) would *shorten* the measured memory time and so cannot manufacture the size dependence seen.

**Priority.** Thermal stability of the 4D toric code: DKLP 2002; Alicki et al. 2010. L-independent 2D memory time: Alicki–Fannes–Horodecki. Damage spreading: Derrida–Weisbuch 1987. The only addition is the joint measurement of memory and local thermalisation as a test of B; that joint statement was not located in the literature brief, which also noted that AdS/CFT (a code that is maximally chaotic) already made B implausible on general grounds. This packet makes the same point in a proven passive memory with numbers.

The test came out as holography predicted. What remains of the fracton/memory route is the open question alone, with no mechanism connecting it to non-scrambling. The program's result stands as the map: the responsive-vacuum and closed-whole intuitions are each consistent with known physics and add no law, no state selection, and, now, no memory–scrambling link beyond it.
