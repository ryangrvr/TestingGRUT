# Execution and exposure

The primary target list, profile, comparison windows, comparator and metric were
written before the new recoil run. Existing field profiles, mass budget, halo and
earlier xenon/WIMP degeneracy were already known; this is not a claim to a held-out
empirical prediction. After viewing the primary result a coarse 27-point nuisance
challenge allowed the comparator a different halo; it is labelled secondary.

The first output was extended with the root of the already-computed form factor and
the minimum yield adjustment. This did not change primary windows, inputs or fit.
The stricter16-point recoil quadrature and independent radial controls were added
for verification of the reported numbers. No failed scientific test was retuned.

One stale model.py path did not exist; the actual profiles.py and stored refined
profile were read. An exploratory arXiv identifier1407.1859 was an unrelated paper
and is not used as a source; the actual composite-source credit is1504.05419.

All new groups have one author. No AI subagents, independent critic, full kinetics,
formation simulation, new state selector, vacuum law or observational fit ran here.
