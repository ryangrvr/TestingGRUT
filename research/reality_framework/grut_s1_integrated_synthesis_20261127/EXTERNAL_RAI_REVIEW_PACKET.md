# External RAI review packet

**Purpose.** Independently assess the post-F5 B/C synthesis. Try to find either a missing qualifying fundamental discriminator or an overstated effective or negative result. Check the synthesis against frozen scopes and original outputs. Publication of the packet is a review handoff, not external replication. [Separate internal critique](INTERNAL_CRITICAL_REVIEW.md)

## Review tasks

1. **State the strongest common mathematical structure.** Check normalization, the declared physical spaces and instruments, compatibility and access. Identify any section in which its dynamical or thermodynamic formula uses an undeclared bath, clock, interaction or ensemble. Check that the EFT does not inherit unproved locality, parameter selection, a cosmological state, a Born derivation or an observer history.
2. **Attempt the F1–F5 implication.** Write the domain, equivalence relation, fixed data and varying physical target for every campaign. Check which results are inverse reconstruction or nonuniqueness, an independent perturbative distinction, empirical selection, or a law-selection obstruction. Show whether any two proofs can be composed without a new class or a calibrated data map. Test F5 both with the supplied inverse wrap and with the reported adverse wrap and incomplete clock. [Obstruction synthesis](FOUNDATIONAL_OBSTRUCTIONS.md)
3. **Challenge the recoverable information.** Re-derive the D4 accessible-state bound and exact collision. Check D7's program independence, phase model, Bell fidelity and blind optimum. Verify the I1 population extension, then test which claims fail for reused baths and jitter. Match I2 work, score and reset rules. Match I3 deadline, full cap, no-record control and free perfect cue. Treat separate-compartment scaling as concentration rather than new collective physics. [Developmental account](DEVELOPMENTAL_EFFECTIVE_THEORY.md)
4. **Audit Candidate 1 by action and version.** Verify the reference branch, finite validation and rotational one-loop binding comparison. Do not promote the numerical allowance into an exact error bound. Check which channels are still missing and which successors change the action or prepare states before transport. Compare the physical H55 stress/work boundaries with conditional abundance outputs. Require matched detector and population inputs before promoting any elastic signature. [Candidate status](CANDIDATE_1_STATUS.md)
5. **Screen surviving novelty and review counterexamples.** Test each result against its named standard comparator and independently search for exact mathematical precedents where priority would matter. Record either an independently supported distinct prediction, a qualified mathematical contribution, a conventional result, or a preserved negative. Review the RRP/SCOUT and published T3 records at the strengths they actually claim.
6. **Report status and proposed corrections.** Return claim, supporting source, tested assumptions, evidence grade, result and any exact changes to the verdict. Reconcile apparent conflicts with version and scope. Include failed checks and unexecuted cases. State explicitly whether each independent result is analytical, a reproduction, or an experimental observation.

The question is whether anything in the record supports an independently warranted fundamental physical principle. Useful negative results and an internally coherent ordinary framework count as distinct outcomes. No new experiment, new model or old acceptance-criterion change is needed to evaluate S1.
