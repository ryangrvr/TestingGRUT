# Exploratory phase-to-charge record

A supplied phase input +/-pi/2 is allowed to interact under the same scalar action. The ideal receiver observable is charge in a separated rightmost radius-12 ball, with threshold tied to the already supplied single-object charge. A missed-encounter control uses outward velocities. This tests a physical record predicate over finite windows; it does not implement its detector or establish consciousness. Design is informed by prior positive-phase results and known reflection symmetry.
