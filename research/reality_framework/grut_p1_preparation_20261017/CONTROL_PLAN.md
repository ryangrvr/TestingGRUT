# Bounded controls frozen before execution

No large formation trajectory or compression worker will be launched.
The primary executable control suite has a 60-second wall budget and a
1-GiB memory budget. On a budget or correctness failure, retain the result;
repairing an identified implementation mistake is disclosed, not a changed
physical protocol. Diagnostics using small receivers are not formation data.

1. Independent two-site ambient tensor construction: partial shifts,
   gauge/flux/support constraint preservation, explicit pair-conversion
   signs, all retained physical matrix entries against the path builder.
2. Exact local loading and conversion, including detuned parameter corners,
   full three-state coherence, work, and reverse conversion. Check the
   analytic Rabi expression and rational sufficient bound. Never discard
   its adjoint. Include a cubic-energy neutral segregated-charge control.
3. Fixed four-event path with two disjoint pumps: every hard-core physical
   number sector and both fuel qubits, no receiver approximation. Compare
   the exact propagated pure state with the product pulse state, energy
   ledger, gauge-dressed near responses and conservative response bounds.
   Mixed-fuel traces may not replace the coherent prepared state.
4. Complete four-event rooted-word geometry with two receiver modes and one
   selected pump: all words, all storage bits, all charge-allowed receiver
   occupations, all physical matter-number sectors, both fuel levels and
   all physical fields at capacity one. The short-step load/conversion
   control uses duration .02 each to exercise a nontrivial boundary estimate;
   it does not claim the primary pi/2 preparation succeeded at N=4. A separate
   short operating comparison uses the primary locally prepared reference
   state and actual coherent receiver. Keep storage-error/return channels.
5. Compare the matter/fuel-vacuum geometry matrix with the archived D1 vacuum
   block; require exact entry agreement, not only matching populations.
6. Evaluate probability/error/resource formulas at N=256 and at the inherited
   S9 threshold. This is formula evaluation only, not those systems' evolution.

All tolerances are ordinary-double diagnostics: matrix-entry/constraint
errors <1e-12, normalized-wavefunction comparisons <1e-10, analytic upper
bounds tested with 1e-10 absolute slack, local linear response with an
explicit Taylor bound. Arithmetic must not be described as outward-rounded.
