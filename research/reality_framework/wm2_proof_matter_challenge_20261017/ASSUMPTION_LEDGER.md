# What the construction supplies and what it derives

This table is part of the physical result, not a proposal to eliminate
all primitives. "Derived" below always means in-class, author-derived.

| Structure | Supplied or derived? | What changing it does |
|---|---|---|
| Quantum Hilbert space, Born measurement and external time | Supplied | No derivation or alternative is tested here |
| Ordered, reversible single-end append/pop grammar | Supplied | Supplies the path dimensional class and growing prefix word cost; generic reconnections need new analysis |
| Which event labels attach and in what order | Generated by the quantum law | No fixed event-pair adjacency is installed; root/word symmetries are retained |
| Connected path once m labels are attached | Grammar consequence | Connectivity is conditional on assembly, not a separately selected low-energy dimension |
| Independent storage detunings and common g interval | Supplied parameter class; S9 derives uniform bounds over it | Arbitrary other disorder classes are not covered |
| Bosonic receiver, charge capacity N-1, vacuum seed | Supplied model/preparation | Vacuum is forced within that exact bondless charge-consistent seed; changing it requires a new joint preparation |
| Receiver path, bandwidth, contact spectrum | Supplied auxiliary structure | Correlation decay and positive overlap enable formation; the flat-receiver variant has an all-time obstruction |
| Receiver mode count 64N^2 | Supplied resource sequence | Provides a no-return estimate through O(N^2); necessity or economy is not proved |
| Assisted normalization g/N | Supplied | The rate/time balance and commutator remainder depend on it |
| Macroscopic partial assembly at N>=2^28 | Derived in S9, independent review pending | This is a sufficient bound, not a predicted transition or small-N result |
| Original probe a hops along occupied bonds | Supplied microscopic rule | S9's geometry/transport link uses this; class C permits new-species counterexamples |
| Root-pair source and number variance 1/4 | Supplied recipe; variance computed | Does not identify the original CP-12 charged matter or all matter sectors |
| Operational prefix metric, response front, growing arrival distance | Derived within that law and recording protocol | Exponential fronts depend on the word grammar and allowed hopping support |
| Recording and injection | Supplied interventions | Their fields, probabilities and system mean-energy changes are counted; apparatus/reset work is unspecified |
| Dimension selected by dynamics | Not derived | A longer path or a propagation cone does not select three dimensions |
| Shared geometry for new matter species | Not forced in declared class C | WM2-MC bypasses it with bounded couplings and nonzero nearby hopping |
| Common relativistic cone, gravity, empirical prediction | Not derived | This packet makes no claim on these objectives |

The two exact counterexamples isolate explanatory work. Changing only
the permitted b coupling can preserve formation while destroying shared
matter locality. Changing only the receiver to a flat spectrum can
retain the mode count and charges while obstructing formation. Neither
revises the original WM2 Hamiltonian or invalidates its narrower theorem.
