# Short adversarial review route

Do not begin by assuming the reported operating pass. It is
author-derived and depends on the pinned earlier proofs.

1. Check the actual two-charge source in REAL_AXIS.md against B2-AS.
   Verify the divided-difference factor (4)-(9) on its true branch.
   It must not silently become a scalar finite-defect Jacobi operator.
2. Check the complete boundary moments (17)-(18), including the max
   rather than sum boundary-word length and the m=0 cancellation.
3. Try to break the localized real-axis inverse, the fuel denominator,
   the rank-one jump and the density ratio (14)-(16),(29). Finite
   off-real matrix identities alone would not establish these.
4. Check (19)-(27) from the positive-word generating function. The
   differentiated Neumann argument is coordinatewise; claiming norm
   differentiation of outgoing plane waves would be false.
5. Check the ONE-maximum velocity proof and the GLOBAL ell2 remainder
   (31)-(33). Receiver-distance decay alone would not control near-
   source missed probability.
6. Reconstruct the ac-central packet (34), with Jacobian, both phases,
   fuel-site offset n+2 and hard-cut endpoints. Challenge the uniform
   continuous-window tail sum (40)-(43).
7. Check the orthogonal-component interference inequality. A central
   spectral weight is not itself arrival probability. Singular and
   noncentral pieces must remain in the complementary original state.
8. Finally audit B2-SO's inherited same-space finite-host comparison
   and its two-source reconstruction, not only this packet's scalar
   constants. One-source probability a gives joint reference a^2.

Reproduction: run `python run_controls.py primary`, then the identical
`python run_controls.py replay`, in a fresh copy without archived worker
metadata. EXECUTED_SOURCES.json identifies the exact proof/code freeze.
The archived run uses only Fractions and rational outward square roots.
`python verify.py` checks saved source/output identity and integrity.
Neither command is independent validation of the all-size mathematics.

An explicit counterexample in an allowed length/time or a failed
load-bearing inequality requires a correction. Refuting a sufficient
intermediate bound alone is not necessarily a physical operating failure.
No reviewer has been contacted and no external validation is claimed.
