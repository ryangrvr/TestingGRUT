# Emergence ledger, version 0

Claude, for the owner (issue #13); an idea from the owner's discussion. Each feature of the M2 universe is classified
by **origin**:
- **primitive:** assumed by the framework;
- **supplied:** a chosen number or structure;
- **emergent:** produced by dynamics from earlier structure;
- **selected:** one of several dynamical outcomes, picked by a criterion the dynamics evaluates;
- **apparent:** an effective description that exists only in a regime.

Each entry also gives the onset (when the feature first becomes operative), what fixes it, and what would change the
entry. Sources: our tracks [C], standard physics [R]. The ledger is bookkeeping, not a law. Its use is to show where a
principle would have to act.

## What the ledger shows

- **Every "selected" feature in M2 is selected by standard dynamics from supplied inputs.** Every primitive or supplied
  entry is a place a GRUT principle would have to act, and at present it acts on none.
- **Features fixed at the same epoch from the same kind of input are candidates for a common origin.** That is a
  concrete way to read "maybe things emerged at the same time". The ledger's sharpest such pair [A, not computed] is
  the two CP-odd phases:
  - the holder phase, which sets the dark charge (M2-X's relic is 99.97% asymmetric);
  - the lepton phase δ, which sets η_B.

  M2 supplies them separately. If one CP-odd source set both, which is the asymmetric-dark-matter or "cogenesis" idea
  in the literature [R], one input would go and the ratio Ω_DM/Ω_B ≈ 5.4 would become a relation instead of two fits.
  It would be a genuine reduction of inputs. It is not yet a GRUT principle, and it would need its own pre-registered
  test.
